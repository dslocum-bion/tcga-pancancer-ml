# Pan-Cancer RNA-seq Analysis: Clustering and Cancer Type Prediction

## Project Overview
This project analyzes TCGA Pan-Cancer RNA-seq gene expression data to investigate whether unsupervised learning can recover known cancer types and whether supervised machine learning models can accurately predict cancer type from gene expression profiles.

## Research Questions
1. Do unsupervised clusters derived from tumor gene expression profiles correspond to known TCGA cancer types?
2. Can we accurately predict a tumor’s cancer type from its gene expression profile, and which genes contribute most to these predictions?

## Dataset
Uses the TCGA Pan-Cancer (PANCAN) RNA-seq dataset hosted by UCSC Xena:
- Gene expression (RNA-seq)
- Phenotype labels including cancer type

Data source:
https://xenabrowser.net/datapages/?cohort=TCGA%20Pan-Cancer
